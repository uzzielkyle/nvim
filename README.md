# ME-NIMAL NVIM
My personal Neovim configuration

## Philosophy
Keep it minimal for optimal memory usage but keep it productive.
- Prefer Neovim's built-in features
- Add plugins and external toolings deemed as necessary
- Avoid unnecessary abstractions

Boring is my cool~

### Reason behind
My daily driving machine is a Huawei D15 laptop that features an intel i5 10th gen and a soldered 8GB RAM. I'd like to maximize this station as much as I can so I optimize my softwares. Yes, I'm an optimization enthusiast :)

## Stack
- Plugin manager: `vim.pack`
- File tree: `nvim-tree`
- Tree-sitter: `tree-sitter-manager`
- Completion: `blink.cmp`
- Formattig: `conform.nvim`
- Linting: `nvim-lint`
- Fuzzy finding: `mini.pick`
- Colorscheme: `base46`
- LSP: `vim.lsp`

## Focused Languages
- Python
- JavaScript
- TypeScript
- TSX
- Lua

## Requirements
- Neovim 0.12+
- Git
- Tree-sitter CLI
- Required language servers, formatters, and linters

## Installation
```bash
git clone <repo> ~/.config/nvim
nvim
```
